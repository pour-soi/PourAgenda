## 0.1.0 - Initial release

### Added

- Added privacy-focused appointment and schedule manager built with Next.js and Supabase.
- Added authenticated calendar workflows, category-based organization, contacts, reminders, exports, and PWA support.
- Added Row Level Security schema, grants, triggers, and safety checks for a self-hosted deployment model.
- Added OpenNext + Cloudflare Workers deployment path and production-ready environment documentation.

### Changed

- Initial baseline for public deployment and operator self-hosting controls.

### Fixed

- Established first-party verification scripts and documentation-driven hardening for secure operation.

### Security

- Enforced browser-only use of publishable key and documented explicit constraints against committed secrets or personal data.
