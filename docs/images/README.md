# Screenshot provenance

The PourAgenda screenshots in this directory are generated by `tests/e2e/visual-evidence.spec.ts` from the guarded `/privacy/layout-preview` route.

The fixture:

- uses synthetic user, category, appointment, date, and UTC time-zone values;
- intercepts Supabase REST requests and returns local fixture objects;
- rejects fixture write requests;
- is enabled only when `POURAGENDA_LAYOUT_PREVIEW=1`;
- is not available in a normal production build.

Before committing regenerated screenshots:

1. inspect every image visually;
2. confirm no email, production URL, account identifier, real event, location, or API response is visible;
3. confirm PNG text and EXIF metadata are absent;
4. run the source and credential scans.

These screenshots are original PourAgenda project assets released under the repository’s MIT License.
